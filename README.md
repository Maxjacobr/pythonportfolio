# pythonportfolio

This portfolio contains the programs I created throughout my AP Computer Science Principles course. Each project demonstrates my understanding of core computing concepts such as algorithms, user input, data processing, and problem‑solving. Together, these projects show my growth as a programmer and my ability to design interactive, user‑focused programs.

PROJECTS

Rock Paper Scissors
A simple interactive game where the user plays against the computer. The program uses conditional logic, randomization, and a game loop to track wins, losses, and ties.

Pokemon Battle Simulator
A turn‑based battle program inspired by the Pokémon series. The user selects a Pokémon, each with unique stats, and battles an opponent. This project uses functions, abstraction, and modular design to organize attacks, damage calculations, and turn order.

City Recommender
A recommendation program that suggests cities based on user preferences. It uses branching logic and data structures to match user input to categories such as climate, population, or lifestyle.

ATM Simulation
A program that models a basic ATM system. Users can deposit money, withdraw money, and check their balance. The project includes input validation, error handling, and state management to simulate real‑world banking behavior.

Coffee Recommender
A personalized coffee suggestion tool. The program asks the user about flavor preferences, caffeine level, and sweetness, then recommends a drink based on their answers. This project focuses on user‑centric design and conditional decision‑making.
